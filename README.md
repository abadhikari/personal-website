# React TypeScript Frontend for [abhinnaadhikari.com](https://abhinnaadhikari.com)

## Description
This repository contains the React TypeScript Frontend for [abhinnaadhikari.com](https://abhinnaadhikari.com). The project is hosted on Vercel. 

## 🛠️ Getting Started

### Prerequisites
Ensure you have the following installed:
- [Node.js](https://nodejs.org/) (v16+ recommended)
- [npm](https://www.npmjs.com/) or [yarn](https://yarnpkg.com/)
- [Vercel CLI](https://vercel.com/docs/cli) (optional, for local development and testing)

### Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/your-username/your-repo-name.git
   cd your-repo-name
2. Install dependencies:
   ```bash
    npm install
    # or
    yarn install
3. Start the development server:
   ```bash
    npm start
    # or
    yarn start

### 🧪 Local Development with Vercel
To emulate the Vercel production environment locally:
1. Install the Vercel CLI globally:
   ```bash
    npm install -g vercel
2. Authenticate with Vercel:
   ```bash
    vercel login
3. Run the local server:
   ```bash
    vercel dev
4. Access the local development server at:
   ```bash
    http://localhost:3000
